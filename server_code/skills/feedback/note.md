# Note 模板：给予与接受反馈（Feedback）

## 技能说明
适用场景：需要向上级/同级/下级提反馈，或收到反馈后不知如何回应，或想改善团队的反馈文化。

---

## 基础信息字段（baseline_fields）

| 字段 | 标签 | 必填 | 说明 |
|------|------|------|------|
| `feedback_direction` | 反馈方向 | ✅ | 给上级 / 给同级 / 给下级 / 接收反馈 |
| `main_issue` | 核心问题 | ✅ | 需要反馈的具体行为或收到的具体反馈 |
| `relationship_quality` | 双方关系 | ✅ | 关系好/一般/紧张，影响反馈方式 |
| `desired_outcome` | 期望结果 | ❌ | 反馈后希望对方改变什么 |
| `previous_attempts` | 已有尝试 | ❌ | 之前有没有提过，对方如何反应 |

---

## AI 初始化问卷话术

**开场白：**
> "反馈是一件很微妙的事，方式比内容更重要。告诉我一些基本情况，我来帮你想想怎么说。"

**问卷问题（只问缺口字段）：**
1. `feedback_direction` 缺失：「这次是你要给别人提反馈，还是你收到了反馈不知道怎么应对？如果是给别人，是上级、同事还是你的下属？」
2. `main_issue` 缺失：「具体是什么行为或事情让你觉得需要提出来？」
3. `relationship_quality` 缺失：「你和对方平时关系怎么样？」
4. `desired_outcome` 缺失：「你希望提完这个反馈之后，对方有什么改变？」

---

## baseline_text 示例

```
反馈方向：给同级（平级同事）
核心问题：对方总在会议上打断我说话，已经发生 4-5 次
双方关系：表面还可以，但有些竞争关系
期望结果：让对方意识到这个习惯，下次能改
已有尝试：没有正式提过，只是开玩笑说了一次，没用
```

---

## 更新触发条件

- 提到反馈结果（对方接受/抗拒/关系变化）
- 提到反馈对象发生变化
- 提到自己收到了新的重大反馈
