# Note 模板：绩效评估（Performance Reviews）

## 技能说明
适用场景：准备绩效评估、争取好的评级、晋升答辩、复盘被低评的结果。

---

## 基础信息字段（baseline_fields）

| 字段 | 标签 | 必填 | 说明 |
|------|------|------|------|
| `review_cycle` | 考核周期 | ✅ | 几月一次，下次评估时间 |
| `last_rating` | 上次评级 | ✅ | A/B/C 或具体描述 |
| `key_achievements` | 核心成就 | ✅ | 本周期最重要的 2-3 件事 |
| `career_goal` | 职业目标 | ✅ | 这次评估希望达到什么结果（保级/晋升/加薪） |
| `boss_expectation` | 上级期望 | ❌ | 上级明确表达过的期望或不满 |
| `peer_perception` | 同事评价 | ❌ | 360 评估中可能出现的问题点 |

---

## AI 初始化问卷话术

**开场白：**
> "要帮你准备绩效评估，我需要了解你的工作情况和目标。"

**问卷问题（只问缺口字段）：**
1. `review_cycle` 缺失：「你们公司多久评一次绩效？下次评估大概是什么时候？」
2. `last_rating` 缺失：「上次绩效结果是什么？评级还是具体反馈？」
3. `key_achievements` 缺失：「这个周期你觉得最拿得出手的 2-3 件事是什么？」
4. `career_goal` 缺失：「这次评估你最想争取的是什么？保住现在的评级、争取晋升，还是争取加薪？」
5. `boss_expectation` 缺失：「上级有没有明确表达过对你的期望或不满意的地方？」

---

## baseline_text 示例

```
考核周期：半年一次，下次评估：12月
上次评级：B（良好），目标本次晋升到 B+
核心成就：
  1. 主导支付系统重构，QPS 提升 3x
  2. 带教 2 名新人，均顺利转正
  3. 推动跨部门协作，减少沟通成本
职业目标：本次争取晋升 L5，不满足则至少拿到 A 评级
上级期望：希望我更多参与跨团队项目，技术影响力扩大
```

---

## 更新触发条件

- 提到绩效结果出来了（评级变化）
- 提到开始准备新一轮绩效
- 提到晋升结果（成功/失败）
- 提到上级期望发生了变化
