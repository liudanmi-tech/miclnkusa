# Note 模板：求职面试（Job Interviews）

## 技能说明
适用场景：准备求职面试、模拟练习、面试后复盘、谈 offer 时机判断。

---

## 基础信息字段（baseline_fields）

| 字段 | 标签 | 必填 | 说明 |
|------|------|------|------|
| `target_role` | 目标职位 | ✅ | 职位名称 + 行业/公司类型 |
| `years_experience` | 工作经验 | ✅ | 总年限 + 相关领域年限 |
| `key_strengths` | 核心优势 | ✅ | 2-3 个最拿得出手的技能或经历 |
| `known_weakness` | 已知弱点 | ❌ | 面试中可能被问到的短板 |
| `salary_range` | 薪资期望 | ❌ | 期望区间，影响 offer 谈判时机建议 |
| `interview_stage` | 当前阶段 | ❌ | 一面/二面/终面/等结果/已拿 offer |

---

## AI 初始化问卷话术

**开场白：**
> "来帮你备战面试！先告诉我一些基本情况，这样我给的建议会更有针对性。"

**问卷问题（只问缺口字段）：**
1. `target_role` 缺失：「你在面试什么职位？是哪个行业或类型的公司？」
2. `years_experience` 缺失：「你工作几年了？做这个方向多久了？」
3. `key_strengths` 缺失：「你觉得自己最拿得出手的 2-3 个优势是什么？」
4. `known_weakness` 缺失：「有没有你担心面试官会问到的弱点或空档？」
5. `interview_stage` 缺失：「你现在是在准备面试、正在面试中，还是已经有 offer 在考虑了？」

---

## baseline_text 示例

```
目标职位：后端工程师（大厂，支付/金融方向）
工作经验：5年（后端 4年，支付系统 2年）
核心优势：系统设计能力强、有高并发实战经验、稳定性好
已知弱点：算法基础一般，LC hard 容易卡壳
薪资期望：35-40k，底线 32k
当前阶段：已过字节一面，准备二面
```

---

## 更新触发条件

- 提到面试通过/挂了/拿到 offer
- 提到换目标公司或职位
- 提到薪资期望发生变化
- 提到面试结果复盘后识别出新的弱点
