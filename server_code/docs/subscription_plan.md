## 五、盈利模型

### 单用户月度盈亏

| 档位 | API成本/月 | Apple抽成后月净收入 | **月利润** |
|---|---|---|---|
| Free（3次） | $0.28 | $0 | **-$0.28** |
| Pro 月付 $8.99 | $4.08 | $8.99 × 70% = $6.29 | **+$2.21 ✅** |
| Pro 季付 $25（第1年） | $4.08 | $25 × 70% ÷ 3 = $5.83 | **+$1.75 ✅** |
| Pro 季付 $25（续费） | $4.08 | $25 × 85% ÷ 3 = $7.08 | **+$3.00 ✅** |
| Pro 年付 $90（第1年） | $4.08 | $90 × 70% ÷ 12 = $5.25 | **+$1.17 ✅** |
| Pro 年付 $90（续费年） | $4.08 | $90 × 85% ÷ 12 = $6.38 | **+$2.30 ✅** |

> 📌 Apple 订阅抽成：第1年 30%，连续订阅满1年后降至 **15%**（续费利润显著提升）

### 规模利润预测

> 假设：Free 85% / Pro 15%，付费用户中月付:季付:年付 = 5:3:2
> Pro 按第1年计算（保守），avg 15次录音/月

| MAU | Free 成本 | Pro 利润 | 服务器 | **月净利润** |
|---|---|---|---|---|
| **500人** | -$119 | +$147 | -$25 | **≈ +$3 🎯** |
| **1,000人** | -$238 | +$294 | -$25 | **≈ +$31** |
| **2,000人** | -$476 | +$588 | -$35 | **≈ +$77** |
| **5,000人** | -$1,190 | +$1,470 | -$50 | **≈ +$230** |
| **10,000人** | -$2,380 | +$2,940 | -$80 | **≈ +$480** |

> 🎯 **盈亏平衡点：MAU 约 500，付费率 15% 时即可回正**

## 八、实施清单

### 后端（服务器）

- [ ] 数据库新增字段：`users.subscription_tier`（`free` / `pro` / `unlimited`）
- [ ] 数据库新增字段：`users.subscription_expires_at` (timestamp)
- [ ] 数据库新增字段：`users.monthly_recording_count` + `users.monthly_reset_at`
- [ ] 接口：录音上传前检查当月次数上限（Free ≤ 3，Pro ≤ 30，Unlimited 无限）
- [ ] 接口：图片生成时按 tier 控制张数（Free = 1，Pro/Unlimited = 3）
- [ ] 接口：`POST /api/v1/subscription/verify` — 验证 Apple StoreKit 收据 / JWS Transaction
- [ ] 接口：`GET /api/v1/subscription/status` — 返回当前 tier、到期时间、本月剩余次数
- [ ] 接口：历史记录查询时对 Free 用户过滤 30 天前数据
- [ ] Cron：每月1日 00:00 UTC 重置所有用户的 `monthly_recording_count`
- [ ] Webhook：Apple Server Notifications V2 — 处理续费/取消/退款事件

### iOS 客户端

- [ ] StoreKit 2 接入（`Product.products()` / `Transaction.updates`）
- [ ] App Store Connect 创建3个订阅产品（Pro 月付 / 季付 / 年付，按上表 Product ID）
- [ ] `SubscriptionView` — 订阅选择页面 UI（Free / Pro / Unlimited 三栏对比）
- [ ] Paywall 触发逻辑（录音次数耗尽 / 点击高级功能时）
- [ ] 订阅状态本地缓存 + 启动时服务端同步
- [ ] 按 tier 控制 UI：图片张数显示、档案入口显示/隐藏
- [ ] Restore Purchases 功能
- [ ] 订阅到期前3天 Local Notification 提醒
