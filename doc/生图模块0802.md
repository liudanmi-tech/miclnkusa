## 二、整体流程（共9步）

```
transcript
    │
    ▼
步骤1  更新 image_status = "generating"
    │
    ▼
步骤2  场景类型检测（自动）
    │      ├── 场景1：多人对话 / 单人但声纹非自己
    │      └── 场景2：单人且声纹 = Self（事后自述）
    ▼
步骤3  构建对话文本
    │      ├── 场景1：每行加 [我] / [对方] 标签
    │      └── 场景2：纯口述文本，不加标签
    ▼
步骤3.5  预加载档案列表（仅场景2，纯 DB，无 Gemini）
    │
    ▼
步骤4  Gemini 场景提取
    │      ├── 场景1：单次 prompt，输出1-3个英文场景描述（I / the other person）
    │      └── 场景2：3步合并 prompt（提取人名 → 谐音匹配 → 生成场景）
    ▼
步骤5  参考图准备
    │      ├── 场景1：声纹映射档案照片（_get_profile_reference_images）
    │      │         降级：Gemini 人物外貌推断（_analyze_character_profiles）
    │      └── 场景2：按匹配人名拉取档案照片 + 用户自己的档案照片
    │                 降级：_infer_person_appearance（Gemini 推断外貌描述）
    ▼
步骤6  生成图片
    │      ├── comic_strip_mode=True（AI Chat）：所有场景合并为单张多格漫画（_build_comic_prompt），调用一次生图
    │      └── comic_strip_mode=False（普通/Live）：每个场景并行单独生图（asyncio.gather）
    ▼
步骤7  组装 scene_images 列表（{index, scene_description, image_url, image_base64}）
    │
    ▼
步骤8  保存到 strategy_analysis.scene_images（追加，不覆盖历史轮次）
    │      同步写 sessions.cover_image_url（Moment 列表封面）
    │      若 StrategyAnalysis 尚未创建：暂存到 analysis_stage_detail，最多重试5分钟
    ▼
步骤9  更新 image_status = "completed"
```

## 三、场景类型判断详情

```python
is_narration_mode = False
if speaker_count == 1 and speaker_mapping:
    single_speaker = speakers[0]
    mapped_pid = speaker_mapping.get(single_speaker)
    if mapped_pid:
        p = await db.get(Profile, uuid(mapped_pid))
        if p and p.relationship_type in ("自己", "Self", "self"):
            is_narration_mode = True
```

**绝大多数日常录音走场景1**（两人对话，或用户虽独说但声纹不匹配 Self 档案）。

## 四、步骤4 场景提取——场景1 vs 场景2

### 场景1（对话）

```
分析以下录音对话，识别1-3个最有画面感的场景。

对话角色说明：
- [我] = 用户，画面中固定在左侧
- [对方] = 对话另一方，画面中固定在右侧

规则：
- 使用"I"代指用户，使用"the other person"代指对方（不要用Speaker_0/1）
- 场景描述必须用英文输出

输出 JSON：{"scene_count": 2, "scenes": ["...", "..."]}
```

- **没有人名提取，没有谐音检测**
- 对方是谁对生图完全不透明
- 参考照片只按左/右位置绑定

### 场景2（自述，3步合并 Gemini prompt）

**Step 1** — 从口述文本中提取提到的人名：
```
返回 {"mentioned_people": ["张伟", "老王"]}
```

**Step 2** — 谐音/昵称匹配（_fuzzy_match_profiles）：
```
将提取到的名字与档案列表做谐音/昵称对比
例："老王" → "王磊"，"小李" → "李明"
返回 {"老王": "王磊", "小李": "李明"}
```

**Step 3** — 生成场景描述（使用真实档案名）：
```
返回 {"scenes": ["张伟 is pointing at the whiteboard while 李明 takes notes"]}
```

- **有谐音/昵称检测**，仅场景2生效
- 未匹配到档案的人名写入 `analysis_stage_detail.unmatched_people`，iOS 端读取后弹 toast 提示用户创建档案

## 五、步骤5 参考图准备

### 场景1 参考图
```
get_profile_refs_fn(session_id, user_id, db)
→ 声纹匹配到的档案照片，最多2张（左=用户，右=对方）
```

### 场景2 参考图
```

→ labels = [{"name": "用户"}, {"name": "张伟"}, ...]（有名字绑定）
```

## 六、步骤6 generate_image_from_prompt — 参考图绑定逻辑

### n_refs == 0（无参考图）
```
【重要】按场景描述忠实绘制，不得凭空添加场景描述中未提及的人物。
```

### n_refs == 1（仅用户自己）
```
【重要】画面中只有一个人物（用户本人），严禁添加任何其他人物。
```

### n_refs == 2（双人，场景1典型路径）
```
【重要】画面中左侧人物固定为用户，右侧人物固定为对方。
必须严格按照场景描述中的动作主体来绘制：谁做动作就画谁在做，不能颠倒角色。
```
- 无名字绑定，完全靠左/右位置 + 动作描述让 Gemini 正确归因
- **这是张冠李戴问题的根源**

### n_refs >= 3（多人，场景2典型路径）
```
以下3张参考照片分别对应场景中出现的3个角色：
- 第1张参考图：用户——场景描述中凡提及【用户】的人物均以此照片为外貌参考
- 第2张参考图：张伟——场景描述中凡提及【张伟】的人物均以此照片为外貌参考
- 第3张参考图：李明——场景描述中凡提及【李明】的人物均以此照片为外貌参考
```
- 有名字绑定，动作归因明确
- 支持宠物（is_pet=True）：禁止拟人化，保持动物原形

## 七、风格注入逻辑

在 `generate_image_from_prompt` 中，style_key 从 `IMAGE_STYLE_MAP` 取文本描述：

```python
style_block = (
    "【画面风格 — 最高优先级】以下是本图的核心视觉风格...\n"
    f"{style_prefix}\n"
    "此风格要求是强制性的，优先级高于下方所有其他指令。\n\n"
)
```

prompt 结构：`style_block + position_rule + ref_desc + prompt_body`

末尾追加风格再强调（首尾呼应）：
```
【风格再次强调】整体画面必须完整体现开头所描述的视觉风格，不得在任何画面区域出现与该风格不符的色调、材质或画风。
```

若 `style_references/{key}_ref.jpg` 存在，则额外将图片作为参考图前置（目前 cyber_y2k 无参考图，cyber_punk 有）。

## 八、已知问题

| 问题 | 受影响场景 | 原因 |
|---|---|---|
| **谐音/昵称检测缺失** | 场景1（所有日常对话录音） | 场景1不提取名字，直接用 "I"/"the other person"，不走档案匹配 |
| **动作张冠李戴** | 场景1双人对话 | n_refs==2 时无名字绑定，仅靠左/右位置规则，Gemini 生图容易混淆动作主体 |
| **风格漂移** | cyber_y2k 等无参考图风格 | 仅靠文本描述控制风格，无视觉参考图锚定，已通过强化 style_block 改善 |
| **场景2触发条件苛刻** | 场景2（谐音+名字绑定） | 需要单人录音且声纹匹配为 Self，日常双人对话永远走场景1 |

## 九、关键参数

| 参数 | 来源 | 说明 |
|---|---|---|
| `max_images` | 订阅 tier | Free=1, Pro=3（Yearly=3, Monthly=3, Weekly=3） |
| `comic_strip_mode` | 调用方 | AI Chat=True（多格漫画），普通/Live录音=False |
| `style_key` | 用户设置 / 会话 | 默认 "spider_verse"；缺省 fallback 到 "ghibli" |
| `generate_image_fn` | `main.py` 注入 | `generate_image_from_prompt`（sync） |
| `get_profile_refs_fn` | `main.py` 注入 | `_get_profile_reference_images`（async，场景1用） |
| `fetch_profile_image_fn` | `main.py` 注入 | `_fetch_profile_image_from_oss`（sync，场景2用） |
| `speaker_mapping` | Live 录音 | `{Speaker_0: profile_id}`，普通录音传 None |
