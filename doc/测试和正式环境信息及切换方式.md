### 切换方式

**切到测试环境：**
1. Xcode 顶部 Scheme 切换为 `WorkSurvivalGuide Dev`
2. `AppConfig.swift` 第 58 行：`return true`（当前默认值，通常无需修改）

**切到正式环境：**
1. Xcode 顶部 Scheme 切换为 `WorkSurvivalGuide`
2. `AppConfig.swift` 第 58 行：`return false`

**Release 打包提审：**
- 始终选 `WorkSurvivalGuide` Scheme → Archive
- Release 配置物理锁死 `return false`，忘记改回来也不影响线上

### AppConfig.swift 切换开关位置

```
文件路径：
Models.swift/WorkSurvivalGuide/WorkSurvivalGuide/Shared/AppConfig.swift
第 53–62 行
```

```swift
var useTestServer: Bool {
    #if DEBUG
    return true   // ← 切测试服改 true，切生产改 false
    #else
    return false  // Release 包硬编码，禁止修改此行
    #endif
}
```

## 七、快速切换速查卡

### 切到测试环境（日常开发用）

```
1. Xcode Scheme → 选 WorkSurvivalGuide Dev
2. AppConfig.swift useTestServer → return true
3. 运行后 App 右上角有红色 DEV 角标 = 确认在测试环境
```

### 切到正式环境（验证线上功能）

```
1. Xcode Scheme → 选 WorkSurvivalGuide
2. AppConfig.swift useTestServer → return false
3. 运行后 App 无 DEV 角标 = 确认在正式环境
```

### 打包提审（App Store）

```
1. Xcode Scheme → 选 WorkSurvivalGuide
2. Product → Archive
3. 无需改任何代码，Release 物理锁死走正式服
```

## 八、环境隔离保障

| 风险点 | 保障机制 |
|---|---|
| 测试代码进正式包 | `#if LIVE_MODE_ENABLED` 编译隔离，Release 不编译 |
| 测试数据污染正式库 | 独立数据库，不同 JWT 密钥，token 跨环境无效 |
| 测试文件上传到正式 Bucket | 独立 R2 Bucket `micink-assets-test` |
| 忘记切回正式环境提审 | Release 物理锁死 `useTestServer = false` |
| 两个 App 图标混淆 | Bundle ID 不同（`.dev` 后缀），可设不同显示名 |
